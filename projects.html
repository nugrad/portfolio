Production · Herbion Pharma

End-to-End Sales Forecasting & Shipment Planning

A rolling demand forecast that feeds directly into shipment planning, built end to end inside Microsoft Fabric.

Problem

Inventory and logistics decisions needed forward-looking demand numbers that stayed current as new sales data arrived, instead of a static forecast that went stale.

What I built

  • Data ingestion into a Fabric Lakehouse, followed by EDA and feature engineering in Python.
  • A rolling forecast framework that regenerates demand projections as new data lands.
  • A shipment planning pipeline that converts forecasted demand into logistics requirements.
  • Power BI dashboards for sales trends, forecast outputs and shipment plans, used by decision-makers.

Outcome

Forecasts and shipment plans supported inventory and operational planning in a single connected workflow, from raw data to dashboard.

Production · Centegy Technologies

Forecasting Pipeline Reliability & Train–Inference Debugging

Finding and fixing why predictions in production did not match what the model saw in training.

Problem

A Microsoft Fabric sales-forecasting workflow had mismatches between training and inference, which made prediction accuracy hard to trust.

What I did

  • Traced mismatches through feature analysis, SQL validation and systematic model testing.
  • Validated joins and standardized master data so the same entities lined up across stages.
  • Built reusable checks for pipeline and prediction accuracy, plus Python and SQL scripts to automate data preparation, validation and recurring tasks.

What I built

  • Cleaned raw e-commerce data covering 93K users and engineered 19 features based on first-order behaviour.
